# 🌌 Solar System Simulator

A simple, interactive solar system simulation built using **Python and Pygame**. The project visualizes planetary motion around the Sun, combining programming with the fundamentals of astronomy and gravitational physics.

## 🚀 Features

- Visual representation of the Sun and planets
- Planetary motion based on gravitational physics
- Planetary masses and orbital velocities
- Astronomical distance scaling using Astronomical Units (AU)
- Minimal, scientific visual interface

## 🛠️ Built With

- Python
- Pygame
- Math and Newtonian mechanics

## ⚙️ Getting Started

### Prerequisites
- Python 3.x
- Pygame

## 🪐 About the Project

This project explores planetary motion and orbital dynamics through a visual simulation. It is a learning project focused on Python programming, physics, and interactive visualization.

*Note: This is a simplified model of the solar system. Orbital parameters, simulation speed, and visual scaling may use approximations.*
